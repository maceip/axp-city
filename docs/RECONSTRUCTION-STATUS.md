# Phaser reconstruction — status against the handoff

Companion to [`PHASER-RECONSTRUCTION-HANDOFF.md`](PHASER-RECONSTRUCTION-HANDOFF.md). Each item lists what is implemented, where the evidence is, and what is **not** established. "Verified" means the named test passed on the branch's tested commit against the production build and the real server; screenshots and reports live in `e2e/screenshots/` from that run. Nothing here claims a hardware measurement, a physical device, or a live GitHub campaign unless a row says so.

## Browser backend used for verification

The suite targets the hosted Azure Playwright workspace (`PLAYWRIGHT_SERVICE_URL`). In the environment that produced this branch the workspace answered `401 Unauthorized` because no `PLAYWRIGHT_SERVICE_ACCESS_TOKEN` (or Entra credential) was available, so the runs recorded in `e2e/screenshots/backend-<kind>.json` used the explicit local fallback (`CITY_LOCAL_BROWSER=1`): Chromium (SwiftShader), Firefox and WebKit Playwright builds on Linux. The harness fails loudly rather than switching silently; adding `PLAYWRIGHT_SERVICE_ACCESS_TOKEN` to the Cloud Agent secrets and the CI secrets makes the same suite run in the workspace without code changes (the Chromium CI leg already prefers it).
