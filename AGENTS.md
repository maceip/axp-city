# AXP City working contract

- This repository is `maceip/axp-city`. Verify directory, remotes, status and branch before edits; fetch before choosing a base. Preserve user artwork, persisted integration data and the separate `ai-game-studio` symlink.
- The accepted scope is the core **Town workshop**. Keep one active Phaser 4 renderer, one integer-grid world model in `src/core`, and one default core server. Do not expand the GitHub/Trending feature backlog or restore the retired civic/HUD collage without an explicit request.
- Terrain, placement, road connectivity and vehicle movement must read the same world state. Simulation runs independently of frame rate, camera visibility and sprites. Asset footprints and ground anchors are explicit; do not repair geometry with zoom-dependent scale changes.
- Browser saves are versioned and validated. Do not silently import or transform old SQLite addresses or fractional lot geometry. Core startup must not open those stores, load credentials or start integration workers. Preserve the integration modules for deliberate future migration.
- Use the standard pytest-playwright setup described in `e2e/README.md`; do not rebuild browser lifecycle or hosted-provider selection. Run `npm test`, `npm run typecheck`, `npm run build`, `npm run test:operations`, and `npm run test:e2e` for engine/client/test-harness changes. Keep the same functional checks across Chromium, Firefox and WebKit. Frame-time benchmarks are explicit `npm run test:performance` measurements, outside required CI. Historical `legacy_ui` checks are superseded, not passing coverage.
- Inspect actual near/mid/far screenshots and exercise mouse/touch placement, rejection, save/load, camera and recovery. A compile, screenshot file or unit count alone is insufficient. Hardware performance claims require the actual driver and named device. Do not call SwiftShader a hardware measurement.
- Production deployment is separate from local implementation. Read `docs/DEPLOY.md` before deployment; preserve server data and unrelated services. Report actual tested revision and remaining limitations honestly.
