# Core city art contract, version 1

The original artwork is reproducibly generated by `game/src/core/art.ts`. It has
no downloaded images, fonts, temporary source files, or image-generation step.
Phaser 4 consumes Canvas 2D textures created once at scene startup. Textures are
generated at 2× resolution and displayed at their declared logical dimensions.

The world uses 72×36 pixel, 2:1 isometric cells. World +x projects down-right;
world +y projects down-left. Elevation is zero in this core. Light arrives from
the upper left of the screen. Shadows fall toward the lower right.

| Object   | Occupied footprint                 | Ground anchor from northwest | Logical texture size |
| -------- | ---------------------------------- | ---------------------------- | -------------------- |
| Cottage  | 2×2                                | (2, 2), front corner         | 194×220              |
| Shop     | 3×2                                | (3, 2), front corner         | 230×235              |
| Workshop | 3×3                                | (3, 3), front corner         | 266×266              |
| Tree     | 1×1                                | (0.5, 0.5), trunk center     | 96×122               |
| Vehicle  | 0.69×0.36 body, rotated by heading | (0, 0), pose center          | 66×58                |

`buildingSpriteSpec`, `treeSpriteSpec`, and `vehicleSpriteSpec` are authoritative
for dimensions and fractional texture origins. Position the sprite at the world
anchor and set its declared origin and display size. Depth uses its ground
anchor's projected y. Elevated architectural details are baked into their host
sprite and cannot sort behind it. Buildings retain the same physical dimensions
at every camera zoom.

Terrain and roads are generated directly with `drawTerrain`. Cells carry
grass/dirt/water plus road state. Neighbor masks use N=1, E=2, S=4, W=8. Roads
extend only to compatible neighboring roads; every shared edge has the same
curb and lane width. Water cells paint shore bands only on edges without water
neighbors, supporting all 16 cardinal masks. Cell texture variation depends on
world coordinates, never camera or chunk position. Chunk generation may bake
the Graphics output once and reuse it while panning.
